# GSoC 2026 Project Journal: RoaringBitmap Functions for Apache Fluss

This file serves as the central hub for my Google Summer of Code 2026 project. Instead of a static document, this is a living journal to track my progress, challenges, and learnings as I implement native RoaringBitmap functions in Apache Fluss.

## My Mission

My goal is to make powerful bitmap-based analytics a seamless, out-of-the-box experience for Apache Fluss users. By implementing and registering a core set of RoaringBitmap functions directly into the Flink SQL layer, I will remove the need for custom UDFs and reduce the friction of performing high-performance, real-time analytics.

### Real-Time User Profile Quickstart ([#2669](https://github.com/apache/fluss/pull/2669))
*   **Goal:** Create a comprehensive, end-to-end tutorial demonstrating a real-world use case for the new FIP-37 bitmap functions.
*   **Status:** This PR has been a long-running effort, evolving from a simple documentation piece to a full-fledged, reproducible quickstart guide. It was initially blocked by the lack of native bitmap functions and external UDFs. Now that FIP-37 is complete, I am updating it to use the native functions.
*   **Challenges:** Uncovered a critical `ClassNotFoundException` during testing, which led to the investigation and fix in PR #3981.

### Flink Connector Shading Bugfix ([#3981](https://github.com/apache/fluss/pull/3981))
*   **Goal:** Fix a critical `ClassNotFoundException: org.roaringbitmap.RoaringBitmap` that prevented the FIP-37 functions from running in a production-like Flink environment.
*   **Status:** After a deep dive into Maven dependency management and the `maven-shade-plugin`, I identified the root cause and submitted a fix. The PR correctly relocates and includes the RoaringBitmap dependency in the final Flink connector JAR.
*   **What I learned:** Gained a much deeper understanding of Java dependency management, classloaders, and the complexities of building shaded uber-jars for Flink connectors. This was a challenging but incredibly valuable real-world debugging experience.
